#  Car Rental Management System

A Python-based Command Line Interface (CLI) application for managing car rentals, vehicle selection, pricing calculations, and customer invoicing. Originally modeled from C++, this version provides a structured execution flow in a Jupyter Notebook format (`.ipynb`).

---

##  Features

* **Interactive Menu & Selection**: Allows customers to select from available car brands (Tesla, Hyundai, Ford).
* **Model-Based Pricing**: Dynamically calculates rental rates based on the manufacturing year/model tier of the vehicle.
* **Vehicle Availability Tracking**: Keeps track of rented status to prevent double-booking.
* **Automated Invoicing**: Formats and prints a detailed customer invoice including invoice numbers, rental duration, and total cost breakdown.
* **State Reset**: Provides an option to clear rental statuses upon transaction completion.
